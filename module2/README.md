# Module 2 – Gig & Matching Service

Separate service folder for gig creation, gig discovery, skill matching, applications, and client applicant review. It shares identity/authentication and student skill data with Module 1. See `API.md` for setup and endpoint details.

The `frontend/` directory is reserved for the Module 2 Next.js screens; the API is ready to connect to the existing Next.js app using `NEXT_PUBLIC_MODULE2_API_URL=http://localhost:5001/api`.
